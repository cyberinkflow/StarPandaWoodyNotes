## 🐾 幕後故事

這是星光小熊貓體系列的第二個字型，在各位旅人看到這個頁面的時候，我已經開始寫第三套字型了 😎

雖然2026年八月才發布，但其實我在2026年初就已經完成這套字型七八成的書寫工作，一直拖著沒有發布是因為我想不到要叫什麼名字（。）

過去一年的生活中發生了一些比較大的震盪，在心情起伏不定的時候，我透過不停地寫字，讓自己的狀態平靜下來，也可能是這種原因，讓我自然寫出了比較樸質、工整的木質調吧。

有別於幼兒風的隨性稚氣，木質調與其說是書寫，不如說是在刻字，一筆一劃都小心翼翼地在平板上刻出痕跡，用力程度甚至磨損了好幾張類紙膜……。但我又不希望筆劃變得太過於呆板，還是選擇保留了一些自然的顫抖、歪斜筆觸，打破中文字慣有的長短、對稱結構，想要呈現出不一樣的效果。

第二次寫幕後故事，發現不太知道要寫什麼了，就……就先說到這邊為止吧。期待在不同的創作角落，看到星光小熊貓體木質調的蹤跡。
